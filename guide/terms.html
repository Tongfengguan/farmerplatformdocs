专业术语与核心技术核心 (Glossary & Tech Stack) ​

在 Farmer Platform 的开发与维护过程中，我们引入了一系列现代化的技术栈。本章节对项目中涉及的所有核心专业名词进行了解释，并附带了官方文档链接，便于开发者查阅。

前端技术 (Frontend Technologies) ​

1. Vue 3 ​

  • 说明: 渐进式的 JavaScript 框架，用于构建用户界面。本项目严格采用 Composition API (组合式 API)，通过 setup 语法糖组织组件逻辑，使得逻辑复用和代码结构更加清晰。
  • 应用场景: src/views 与 src/components 下的所有交互式页面构建。

2. Vite ​

  • 说明: 新一代的前端构建工具。与传统的 Webpack 相比，它利用了浏览器原生的 ES 模块特性（ESM），在开发环境下实现了几乎无延迟的极速冷启动（Cold Start）和热模块替换（HMR）。
  • 应用场景: 本项目的开发服务器与生产环境打包工具（由 vite.config.js 驱动）。

3. Pinia ​

  • 说明: Vue 的专属状态管理库（State Management），作为 Vuex 的现代替代品出现。它支持完全类型推断，取消了传统的 Mutations，直接使用 Actions 来进行状态修改。
  • 应用场景: 位于 src/stores 目录下，如 auth.js 和 platform.js，负责全局的用户鉴权状态和平台公共状态管理。

4. Element Plus ​

  • 说明: 基于 Vue 3，面向设计师和开发者的组件库。本项目中进行了深度定制，抛弃了死板的原生样式，结合项目本身的“Harvest”设计语言进行了全局重构。
  • 应用场景: UI 组件，如表单输入 <el-input>、弹窗 <el-dialog>、分页 <el-pagination>。

5. Axios ​

  • 说明: 基于 Promise 的 HTTP 客户端，可运行在浏览器和 Node.js 环境中。本项目通过 src/utils/http.js 对 Axios 进行了请求与响应拦截器（Interceptors）的二次封装。

后端技术 (Backend Technologies) ​

1. Spring Boot 3 ​

  • 说明: 建立在 Spring 框架基础上的快速开发脚手架，以“约定大于配置”为原则，极大简化了企业级 Java 应用的开发流程。Spring Boot 3 是一个重大升级版本，要求 Java 17+ 基线（本项目使用 Java 21）。
  • 应用场景: backend/farmer_platform 的整体运行框架。

2. Java 21 ​

  • 说明: Java 的 LTS（长期支持）版本。引入了虚拟线程（Virtual Threads，提升高并发能力）、记录模式（Record Patterns，简化 DTO 定义）等现代化特性。
  • 应用场景: 后端服务的基础运行环境语言。

3. Spring Data JPA ​

  • 说明: 基于 JPA（Java Persistence API）规范的持久层框架，开发者只需定义接口并遵循命名规范，即可自动生成相应的 SQL 执行逻辑，大幅减少模板化代码。
  • 应用场景: 实体映射与数据库操作（例如 UserRepository 和 ProductRepository），项目中广泛应用了其内置的 Pageable 进行数据分页。

4. JWT (JSON Web Token) ​

  • 说明: 一种开放标准 (RFC 7519)，定义了一种紧凑且自包含的方式，用于在各方之间以 JSON 对象安全地传输信息。此信息经过数字签名，可以被验证和信任。
  • 应用场景: AuthInterceptor 中进行无状态的用户身份验证。

5. DTO (Data Transfer Object) ​

  • 说明: 数据传输对象。一种设计模式，用于在系统不同层或不同服务之间传递纯粹的数据。它可以隐藏底层的数据表结构设计，增加数据传输的安全性。
  • 应用场景: 位于后端的 dto 包，严格隔离数据库实体与前端接收的数据模型。

智能化技术 (AI & Data) ​

1. FastAPI ​

  • 说明: 一个现代、快速（高性能）的 Python Web 框架，基于标准的 Python 类型提示。它天生支持异步编程（async/await），是构建高性能 AI 服务的理想选择。
  • 应用场景: ai-agent/main.py 中的 RESTful 接口与 SSE 流式推送。

2. DeepSeek-V3 ​

  • 说明: 一款高智能的大语言模型（LLM）。通过先进的 Transformer 架构训练，擅长长文本总结与逻辑推理。
  • 应用场景: 平台的 AI Agent 引擎，提供农产品数据智能聚合与商业报告。

3. LangChain Python ​

  • 说明: 用于开发由大型语言模型（LLMs）驱动的应用的 Python 框架。它通过 bind_tools 和 ainvoke 极大地简化了 LLM 与外部系统（后端 API）的交互。
  • 应用场景: 位于 ai-agent/engine 中，负责 Tool Calling 的核心逻辑。

4. SSE (Server-Sent Events) ​

  • 说明: 一种允许服务器向客户端单向推送事件的 Web 技术。利用 HTTP 连接保持打开状态，非常适合 AI 生成的实时打字机效果。

UI/UX 设计理念 ​

1. Bento Grid (便当盒网格) ​

  • 说明: 一种现代化的 UI 布局模式，将信息模块化分割在多个尺寸不一的矩形卡片中，形成错落有致但秩序井然的视觉效果。

2. Floating Island (悬浮岛屿) ​

  • 说明: 导航栏、侧边栏或主要内容区域不与页面边缘直接贴合，而是保留一定的 Margin，并配合柔和的阴影（Drop Shadow），产生元素悬浮在背景色之上的空间层次感。
