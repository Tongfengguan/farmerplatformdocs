智能体服务 (AI Agent) ​

在 Farmer Platform 中，我们引入了基于大语言模型（LLM）的智能体作为平台的“超级数据分析师”。该模块位于 ai-agent/ 目录，利用了 Python 生态 的强大 AI 能力。

1. 技术架构选型 ​

  • 运行环境: Python 3.10+
  • Web 框架: FastAPI (异步高性能 Web 框架)
  • LLM 引擎: DeepSeek API (V3 聊天模型)
  • 开发框架: LangChain Python
  • 工具调用: 模块化 Engine 架构 (Modular Engine)
  • 通信协议: Server-Sent Events (SSE) 流式传输

2. 模块化 Engine 架构 ​

为了保证 AI 能力的可扩展性，我们将所有的工具调用逻辑封装在 engine/ 目录下：

text
ai-agent/
├── main.py                   # FastAPI 入口与 SSE 路由
├── engine/                   # 核心智能体引擎
│   ├── __init__.py           # 工具聚合与导出
│   ├── context.py            # 请求上下文管理 (ContextVar)
│   ├── products/tools.py     # 商品查询工具
│   ├── orders/tools.py       # 异常订单分析工具
│   ├── dashboard/tools.py    # 数据大屏聚合工具
│   └── ...                   # 其他领域工具

2.1 鉴权上下文传递 (ContextVar) ​

由于 Python 的 httpx 调用是异步的，为了确保 AI 调用后端接口时能携带当前管理员的身份（JWT Token），我们使用了 contextvars.ContextVar：

  1. main.py 在接收到前端请求时，从 Header 中提取 Token 并存入 request_token。
  2. engine/context.py 中的 get_headers() 会自动从当前异步上下文中读取该 Token。
  3. 所有的 Tools 在调用后端接口时，都会自动携带该身份证明，确保数据访问安全。

3. Tool Calling (工具调用) 机制 ​

通过 LangChain 的 bind_tools 功能，AI 具备了“感知并调用”后端接口的能力：

  1. 工具声明: 每一个 Python 函数都通过 @tool 装饰器或 BaseTool 子类进行定义，并配有详尽的中文描述。
  2. 意图决策: DeepSeek-V3 接收到用户问题后，会自动判断是否需要调用某个工具。
  3. 异步执行: LangChain 拦截到决策后，通过 ainvoke 异步调用后端 Spring Boot API。
  4. 数据汇聚: 工具返回的 JSON 数据被注入到 LLM 的上下文中，作为其分析的“客观事实”。

4. 极致安全：Safe Summary Mode ​

为了保证输出内容的纯净度和专业性，系统实施了 Safe Summary Mode (安全总结模式)：

  1. 第一阶段 (Action): AI 自由思考并触发多次工具调用，收集原始业务数据。
  2. 第二阶段 (Refine): 丢弃并重置所有中间的工具调用记录（屏蔽 XML 标签和函数名）。
  3. 第三阶段 (Summary): 使用一个全新的、受限的 Prompt 引导 AI 对收集到的原始 JSON 数据进行总结。
    • 输出要求: 3-4 个要点，200 字以内。
    • 内容要求: 直接给出业务洞察与行动建议。

5. SSE 前端集成 (Streaming) ​

FastAPI 通过 StreamingResponse 与前端 Vue 3 实现无缝流式对接：

  • 服务端: 实时迭代 streaming_llm.astream() 生成的内容，并通过 JSON 序列化推送到 SSE 通道。
  • 数据清洗: 在 main.py 中通过 sanitize_content 正则表达式过滤掉可能残留的 AI 内部指令标签，确保前端用户看到的只有纯净的文字。
  • 前端: 使用 ReadableStream 进行逐字渲染，实现极致的交互体验。
