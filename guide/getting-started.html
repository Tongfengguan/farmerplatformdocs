快速开始 (Getting Started) ​

本指南将引导您在本地环境中从零开始运行 Farmer Platform (智慧农产品交易平台)。

本平台采用微服务分离架构，主要由三大核心服务组成：

  1. Frontend (Vue 3 客户端应用)
  2. Backend (Spring Boot 3 核心业务接口)
  3. AI Agent (Python/FastAPI 智能决策服务)

环境准备 (Prerequisites) ​

在运行项目前，请确保您的本地开发环境已经安装了以下运行时和工具：

  • Node.js (>= 20.19.0 或 >= 22.12.0)
    • 说明：基于 V8 引擎的 JavaScript 运行环境，用于运行前端构建工具。
  • Python (>= 3.10)
    • 说明：用于运行基于 FastAPI 和 LangChain 的 AI Agent 服务。
  • Java JDK (>= 21)
    • 说明：Java 平台标准版的开发工具包，支持了诸如虚拟线程 (Virtual Threads) 等最新特性。
  • MySQL (>= 8.0)
    • 说明：开源的关系型数据库管理系统，存储了所有的业务与系统配置数据。
  • Git (最新版本)
    • 说明：分布式版本控制系统，用于代码的拉取与同步。

启动后端服务 (Backend API) ​

后端服务负责所有的核心业务逻辑（订单、文章、用户鉴权等），并暴露 RESTful API。

  1. 数据库初始化
    • 创建名为 farmer_platform 的 MySQL 数据库。
    • 导入提供的初始化 SQL 脚本（如适用）。
    • 在 backend/farmer_platform/src/main/resources/application.properties (或 .yml) 中配置您的数据库连接信息。
  2. 启动服务 打开终端，导航到后端目录并执行：
    bash
    cd backend/farmer_platform
# 使用 Gradle 包装器 (Wrapper) 启动 Spring Boot 应用
.\gradlew.bat bootRun
  3. 验证启动 服务默认运行在 http://localhost:8080/api。如果在控制台看到 Tomcat initialized with port 8080 (http)，说明启动成功。

启动 AI Agent 智能体服务 ​

该服务是平台的“智能大脑”，通过 DeepSeek API 和 LangChain 提供流式 (SSE) 业务分析支持。

  1. 创建并配置虚拟环境 进入 ai-agent 目录：
    bash
    cd ai-agent
python -m venv .venv
# Windows 激活虚拟环境
.\.venv\Scripts\activate
# macOS/Linux 激活虚拟环境
# source .venv/bin/activate
  2. 安装依赖
    bash
    pip install -r requirements.txt
  3. 配置环境变量 创建 .env 文件，填入您的密钥：
    env
    # .env 文件
DEEPSEEK_API_KEY=your_deepseek_api_key_here
  4. 启动服务
    bash
    python main.py
  5. 验证启动 服务默认监听在 http://localhost:3000。前端的 /api/analyze 请求将会代理到此服务。

启动前端用户界面 (Frontend Interface) ​

前端代码位于 src 目录下，负责所有与用户交互的视觉呈现。

  1. 安装包依赖
    bash
    # 在项目根目录下执行
npm install
  2. 启动开发服务器 (Vite Dev Server)
    bash
    npm run dev
  3. 访问平台 应用将运行激在 http://localhost:5173。 您可以分别体验以下两个工作区：
    • 用户侧 (Mall & Articles): 体验农产品商城与自然文化文章。
    • 管理侧 (Admin Dashboard): 使用 tfgkk / 123456 登录管理员账号，体验基于 Bento Grid 设计的数据大屏与 AI 助手。
