整体架构分析 (System Architecture) ​

Farmer Platform 是一个由三部分组成的现代全栈分布式系统。平台旨在通过高内聚低耦合的架构，将智能农业数据、农产品电商与自然生活理念无缝结合。

1. 架构拓扑 (Architecture Topology) ​

整个系统的物理与逻辑部署可以划分为三个核心层级：表现层 (Presentation Layer)、业务逻辑层 (Business Logic Layer) 和 数据与智能层 (Data & AI Layer)。

2. 核心通信协议 (Communication Protocols) ​

2.1 RESTful API + JSON ​

  • 用途: 前端 Vue 3 与后端 Spring Boot 之间所有的核心业务交互。
  • 实现: 基于 HTTP 协议，统一返回 ApiResponse<T> 格式。

2.2 Server-Sent Events (SSE) ​

  • 用途: Admin Dashboard 中的 AI 助手流式响应。
  • 实现: Python AI 服务通过 FastAPI 的 StreamingResponse 实时推送生成的 Token。

2.3 跨语言 Tool Calling (跨服务调用) ​

  • 用途: AI 智能体查询实时业务数据。
  • 实现: Python AI 服务使用 httpx 异步库调用 Java 后端提供的 REST 接口，利用 ContextVar 保持鉴权上下文。

3. 目录结构概览 (Directory Structure) ​

    ├── stores/               # Pinia 状态管理
    ├── views/                # 页面视图 (Admin, User 划分)
    └── utils/                # Axios 封装, 常量配置等

4. 架构设计原则 (Design Principles) ​

  1. 多语言共存 (Polyglot): 后端使用稳健的 Java， AI 服务使用生态丰富的 Python，前端使用响应式的 Vue 3。
  2. 安全隔离: AI 服务作为无状态中间件，不直接连接数据库，所有数据操作必须通过 Java 后端鉴权接口。
  3. 异步优先: AI 服务全程采用 async/await 异步模型，确保在高并发问答场景下仍能保持极低的系统延迟。
