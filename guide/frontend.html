前端设计 (Vue 3 + Pinia) ​

前端系统位于 src/ 目录下，负责呈现 Farmer Platform 的“视觉灵魂”并提供响应式的交互体验。我们采用了目前最现代化的 Vue 3 组合式 API 生态。

1. 核心技术选型 ​

  • 框架核心: Vue 3 (setup 语法糖)
  • 状态管理: Pinia (替代 Vuex，提供更优的类型推断与简洁的 API)
  • 路由控制: Vue Router 4 (支持动态路由与路由守卫)
  • UI 组件库: Element Plus (深度定制，支持按需自动导入)
  • 构建工具: Vite (极速冷启动，秒级 HMR)

2. "Harvest" 自然视觉设计语言 ​

为了贴合“农业、生态、自然”的主题，我们摒弃了传统后台生硬的直角与冰冷的色调，创立了 Harvest 设计语言：

2.1 色彩系统 (Biophilic Palette) ​

  • 祖母绿 (Emerald Greens): 代表生长、生机与农产品，作为按钮、高亮和成功状态的主色调。
  • 琥珀金 (Amber Golds): 代表丰收、阳光，用于点缀、星级评分或警告提示。
  • 晨露灰 (Morning Dew Slates): 替代纯黑或纯白，作为背景、卡片和边框颜色，降低对比度，减少视觉疲劳。

2.2 布局模式 (Layout Patterns) ​

  • Floating Island (悬浮岛屿): 用户端 (UserLayout.vue) 的顶部导航栏和管理端 (AdminLayout.vue) 的侧边栏不再紧贴屏幕边缘，而是采用 Margin + 大圆角 + 柔和阴影 (box-shadow: 0 8px 30px rgba(0,0,0,0.04))，如同悬浮在页面之上。
  • Bento Grid (便当盒网格): 管理员的 Dashboard 仪表盘不再是单调的表格，而是不同尺寸的平滑圆角卡片错落拼接，类似精致的便当盒。

3. 状态管理 (Pinia) ​

我们使用 Pinia 进行全局状态的隔离与管理，所有 Store 位于 src/stores 目录下。

3.1 auth.js (用户鉴权) ​

负责管理登录状态、Token 存储和用户信息。

  • 提供 login(username, password) Action，封装与后端的登录交互。
  • 登录成功后，将 JWT 存储到 localStorage 中，以便 Axios 拦截器自动携带。
  • 提供 logout() Action 以清除本地状态并跳转至登录页。

3.2 platform.js (公共状态) ​

对于全局公用的状态（如购物车数量、深色模式切换等），由 platform.js 统一管理。

4. HTTP 交互与数据驱动 (Axios) ​

前端绝对禁止使用 Mock 数据（mockData.js 已被永久移除）。所有的业务数据必须通过位于 src/utils/http.js 的 Axios 实例进行请求。

请求拦截器 (Request Interceptor) ​

javascript
http.interceptors.request.use(config => {
  const token = localStorage.getItem('token')
  if (token) {
    // 自动在所有请求头中附加 Bearer Token
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})

响应拦截器 (Response Interceptor) ​

统一拦截后端的 ApiResponse<T>，如果发现 code === 401（未授权），会自动触发退出登录逻辑并引导用户至 AuthView。

5. 核心视图解析 (Views) ​

视图按角色权限严格分为两组：

  • User Views (src/views/user/): 面向普通消费者。包括 HomeView (首页), MallView (商城列表，接入分页), ProductDetailView (商品详情与加购), ArticlesView (农耕文化文章列表) 等。
  • Admin Views (src/views/admin/): 面向平台管理员。包括 DashboardView (数据大屏), ProductAdminView (商品的增删改查), OrderAdminView (发货处理) 以及最核心的 AiAssistantView (智能分析助手)。
