了解架构

智能分析引擎 (AI Agent)

深度集成 DeepSeek-V3 大模型与 LangChain，具备上下文感知与自动工具调用（Tool Calling），以流式 SSE 协议提供实时商业数据洞察，彻底革新平台管理。

"Harvest" 视觉设计

首创自然有机设计语言。以“祖母绿”与“晨露灰”为主色调，利用 Bento Grid (便当盒网格) 与 Floating Island (悬浮岛屿) 布局，打造充满生命力的现代界面。

极速响应式前端

基于 Vue 3 Composition API、Vite 和 Pinia 的全响应式架构。严格的数据驱动模型（零 Mock），带来流畅的用户端与管理端体验。

稳如磐石的后端

基于 Java 21 与 Spring Boot 3 构建。原生集成自研 AuthInterceptor 与 JWT 认证，规范化 DTO 模型与 Spring Data JPA 分页，保证高并发下的数据安全。
